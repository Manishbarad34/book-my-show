# Book My Show — Static Demo

This repository contains a static HTML/CSS demo inspired by the BookMyShow layout.

To view locally:

1. Open `css/bookmyshow.html` in your browser.

Optional: serve with a simple HTTP server:

```
# Python 3
python -m http.server 8000

# then open http://localhost:8000/css/bookmyshow.html
```

Created and pushed from the local workspace on your machine.
