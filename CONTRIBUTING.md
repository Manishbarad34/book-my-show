# Contributing

Thanks for your interest in contributing to this project! A few simple guidelines:

- Fork the repository.
- Create a branch for your change: `git checkout -b feature/your-feature`.
- Commit your changes with clear messages.
- Submit a pull request describing the change and why it's useful.
- For bugs, open an issue with steps to reproduce and expected behavior.

Coding style:
- Keep HTML/CSS simple and well-formatted.
- Add small, focused changes per PR.

Maintainer notes: PRs will be reviewed and merged when they pass basic checks.
